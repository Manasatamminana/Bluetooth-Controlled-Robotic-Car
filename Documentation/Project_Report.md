# Bluetooth Controlled Robotic Car

## Objective

To design and develop a Bluetooth-controlled robotic car using Arduino UNO that can be operated wirelessly through an Android smartphone.

## Technologies Used

- Arduino UNO
- Embedded C
- HC-05 Bluetooth Module
- L298N Motor Driver

## Outcome

Successfully developed a Bluetooth-controlled robot capable of moving forward, backward, left, right, and stopping based on commands received from a smartphone.
