# Bluetooth Controlled Robotic Car Using Arduino UNO

## Project Overview

The Bluetooth Controlled Robotic Car is an embedded systems project that enables wireless control of a robotic vehicle using an Android smartphone. The robot receives commands through the HC-05 Bluetooth module, which are processed by the Arduino UNO to control the movement of the DC motors.

This project demonstrates the practical application of embedded systems, Bluetooth communication, and motor control.

---

# Objectives

- Design a Bluetooth-controlled robotic vehicle.
- Enable wireless communication between a smartphone and the robot.
- Learn Arduino programming and hardware interfacing.

## Working Principle

1. Pair the HC-05 Bluetooth module with an Android smartphone.
2. Open a Bluetooth controller application.
3. Send movement commands such as Forward, Backward, Left, Right, or Stop.
4. Arduino receives the commands through serial communication.
5. Arduino processes the command and controls the motors via the L298N motor driver.
